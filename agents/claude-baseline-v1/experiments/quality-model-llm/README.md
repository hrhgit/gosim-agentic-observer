## 把模型输出交给大模型（`band_llm.py`）

任务：为 15 分钟后的一次曝光申报档位。40 个曝光（真实档位 DARK 16、BRIGHT 14、BACKUP 10，稀有档位有意多抽），
kimi-for-coding 低思考强度。"原始数据"是最近 8 次曝光的实测天空水平和档位检查、最近五个时段的公告、最新预报、候选位置的几何因子和档位门槛。

| 谁申报 | 判对 | 平均倍率 |
|---|---:|---:|
| 一律报 DARK | 16 / 40 | 1.0800 |
| 保持基线估计，取最可能 | 33 / 40 | 1.1185 |
| GRU，取最可能 | 31 / 40 | 1.1170 |
| GRU，取期望收益最大 | 29 / 40 | 1.1125 |
| 大模型，只给原始数据 | 30 / 40 | 1.1095 |
| 大模型，只给模型输出 | 31 / 40 | 1.1170 |
| 大模型，两者都给 | 31 / 40 | 1.1135 |
| 大模型，两者都给 + 说明如何结合的提示词 | 30 / 40 | 1.1090 |
| 全对 | 40 / 40 | 1.1370 |

40 题上相差 1–3 题在波动之内。大模型只拿到模型输出时，逐题结果与"GRU 取最可能"相同。延迟中位 3–6 秒。
