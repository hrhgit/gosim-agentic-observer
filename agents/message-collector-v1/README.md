# 专用消息采集版本

只记录收到的消息并执行等待，不观测、不做规划、不报告故障、不调用模型。采集格式与基线 V2 相同，使用已有 `extract_capture.py` 解压。完整交接文字和请求保留；公开目标行用内容指纹代替，重复状态省略。

它用于补齐正式新卡公告、预测、交接和请求的全时段记录。不能获得未发给程序的隐藏天气，也不能提供新观测反馈。数据丢失通知若发出，窗口是基于此采集版本的零次观测计算的，不可替换正常观测运行的失效窗口。

正常等待使用公开允许的最大时长；接近结束时先等待到结束前1秒，再结束，防止最后一批已产生消息没有送达。日志正常退出会写出最后一批压缩记录。线上是否全年完成、是否超出2 MiB，须下载后核实。

此版本分数不用于策略比较，不设置为最终参赛版本。本地测试可显式指定 `--agent 'python3 collector.py' --agent-cwd agents/message-collector-v1/project`。
