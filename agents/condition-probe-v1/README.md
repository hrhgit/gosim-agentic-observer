# 条件强度探测与消息采集版

目的：补齐正式比赛全时段消息，同时用少量短观测测量条件变化。不追逐高分、不调用模型；不把本版本设为最终作品。

每两小时安排一组最短合法曝光。轮流覆盖8个方位与34/40/55/70度附近高度。若粗公告中的活动事件方向变化，可在距离上次探测至少30分钟后增加采样。每组先测活动公告方向（没有方向事件则轮转扫天），再测相反方位。参考方向只是候选，也可能受天气影响。天区中没有合适目标时记录缺测，不能当作零质量。

仅按位置选择最近目标，最多4个安全落在不同光纤中的目标；记录实际方向和目标，固定 BACKUP 节目。不主动报告故障，因此仪器故障不会被本版本修复；故障强度与其他天气影响只能合并测量。与正常比赛版本的故障报告时序不同，不能直接比较总分。

所有新公告、预测、请求（包括完整的中日混合交接文本）、结果、数据恢复通知都用V2压缩采集。公开目标行存内容指纹；重复状态省略。探测上下文附加在对应接收记录的 annotations 中。接近结束时先到结束前1秒接收尾部消息，再结束。

结果下载后，结合 `observations.csv` 的质量字段扣除目标高度及月亮影响，估计 `仪器效率 × 透明度 × 天空质量 / 成像模糊程度` 的综合值。它不是某一个事件的独立强度；方向、时间覆盖、天气混合和缺测会限制结论。失效观测不参加成对估计。比较两次时要求相隔不超过5分钟、实际高度差不超过5度；不满足则保留样本但不报强度比。
