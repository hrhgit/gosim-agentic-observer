# 全局规划第一轮：尚未证明有效

2026-10-05，在本机完成环境适配、小场景训练和独立检验。第一层未通过预先规定的能力门槛，停止扩大训练。当前参赛基线没有被替换；后续第 2–6 层尚未完成，不能把本轮交付称为全方案验收完成。

## 已实现并运行

- `research/global_planning`：原始官方引擎的独立进程适配、只用公开信息的特征、64 单元 GRU、使用相同历史信息但不处理顺序的普通网络、模仿学习、PPO、完整后续收益、权重与优化器恢复、数据来源和阶段门槛。
- `agents/global-planner-v1`：独立接入副本，暴露原规划器候选与原选择；候选预览无状态副作用，最终动作必须与模型所选预览一致。正式入口当前仍执行原规则；学习模型只用于研究桥接入口。
- 自生成 32 个训练、8 个验证、16 个独立测试场景，另有 3 个可穷举诊断场景。每个场景属于固定集合；按验证集选定权重后才生成独立测试数据。
- 两种结构各完成 20 轮模仿、10 轮 PPO，初始种子 101，每轮收集 4 场完整小场景，第 5/10 轮验证。参数没有因测试结果改变。
- 保留各阶段权重、逐场动作、公开反馈、真实分项、训练回报和失败记录。已完成场景可复用；未完成场景从头重跑，不声称支持任意动作中途恢复引擎。

训练采用 PPO 的采样后多次更新方式，并使用完整实际回报；算法出处为 [PPO 原论文](https://arxiv.org/abs/1707.06347)。这里的训练效果以本项目实测为准。

## 结果

| 独立测试的策略 | 16 场平均分 | 相对原规则 |
|---|---:|---:|
| 原规则 | 75.188372 | — |
| 只看眼前科学分 | 73.027344 | -2.8742% |
| 验证集选定的 GRU | 75.387351 | +0.2646% |

选中权重来自**模仿阶段**。PPO 没有提供额外的验证集提升。GRU 与普通网络的最佳验证得分相同，因此这轮也没有证明历史顺序处理有优势。

模型相对原规则的每场分差 95% 配对区间为 `[-0.000570, 0.597506]`；相对眼前规则平均高 3.2317%，分差区间为 `[-0.000380, 6.881233]`。两者均包含零。只有一个延期收益类独立测试场景超过眼前规则，不能据此断言已获得稳定的长期规划能力。

| 穷举诊断 | 当前候选树最优分 | 模型分 | 差距 |
|---|---:|---:|---:|
| 成组请求 | 73.669488 | 73.654451 | 0.015037 |
| 覆盖均衡 | 53.079492 | 53.079492 | 0 |
| 重复观测 | 53.682885 | 53.682885 | 0 |

分别穷举 21、22、33 个完整候选序列。一个案例未达到最优，因此按既定门槛不进入完整赛程。这个差距很小，属于严格门槛未过，不能解释为方法本身不可行。穷举范围仅是原规划器给出的候选，尚不含所有连续指向或主动等待。

剩余收益预测平均绝对误差为 **6.1851 分**，只根据剩余时间的参照为 **15.5577 分**。参照只在训练轨迹上拟合；标签是本次策略实际获得的后续分数，不是最优策略的收益。这说明小场景上的收益估计更准确，但不能替代行动效果检验。

## 验证与来源

- 18 项 Python 检查、8 项 Node 检查通过；TypeScript 构建通过。
- 343 次完成的研究运行全部自然结束，无失败场景；它们包含训练、重复对照和穷举重放，并非 343 个独立场景。
- 所有研究运行的奖励和与官方最终总分最大差值为 `7.11e-15`，低于 `1e-6`。
- 原始官方最佳贡献账本、请求奖励撤回、必做和均匀度结算的定向测试通过；重复贡献不累加，撤销后重算。
- 修改未来天气、尚未发布的请求和公告，当前输入保持一致。特征不包含种子、教师标签或隐藏结算；候选位置置换检查通过。
- 八类场景中，桥接后仍选择原规则时，动作与成绩都和不经过选择钩子的版本一致。权重/优化器恢复后的更新一致。
- 官方引擎 17 个文件来源校验通过；实验源码与冻结版本一致；原基线相对复制时的哈希没有变化。正式公开输入没有改动。
- 一次早期完整 A 卡运行因模型 Python 路径未被官方子进程继承而无有效观测，已通过 `stage0/formal-a/excluded.json` 明确排除。修正为显式传入路径后重新运行；接入副本加载错误会报错退出，不再悄悄变成等待。

以上不能代替完整压力场景下的状态撤销恢复、所有异常协议和容器验证。这些仍列为未完成项。

## 本机成本

使用 Node.js 22 与 Python 3.12、PyTorch 2.14.1。实测选择单进程 CPU：

| 项目 | 实测 |
|---|---:|
| 同一小网络 30 次更新，CPU | 0.0571 秒 |
| 同一小网络 30 次更新，MPS | 3.0058 秒 |
| 两个小场景，单进程 | 4.7711 秒 |
| 两个小场景，双进程 | 4.2321 秒 |
| 独立小场景平均完整运行 | 1.5402 秒 |
| 其中官方模拟计算平均 | 0.00728 秒 |
| 每个选择的 Python 特征整理平均 | 0.656 毫秒 |
| 每个选择的网络计算平均 | 0.556 毫秒 |

TypeScript 候选生成和配套模型耗时仍合并在回调时间中；本轮没有把所有子进程内存相加，不能据此宣称满足 2 GB 限制。

现有规则通过官方完整入口跑 observed-timeline-v4 的 A 卡，正常执行 **2,968 次观测动作**，本地分数 **26363.826642**，墙钟 **367.419 秒**，官方记录 CPU **33.713 秒**、折算计费 **25.473 秒**。这是本机回归材料测速，不是学习模型的完整赛程成绩，更不是线上预测。

仅按 A 卡成本作算术折算，10 轮 × 4 场约 4.08 小时；不含教师数据、验证、优化和桥接额外成本，B–D 尚未测量，因此不作为总训练工期承诺。
