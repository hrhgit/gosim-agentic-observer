## 重建条件与依据

- 地形：从初始交接提取被纠正后的山脊高度，方位宽度暂按45度；高度是交接中的断言，宽度未公开。来源原文见 terrain-height-claims.json。
- 天气事件：恢复所有粗种类/方向的连续公告段；一个段暂按一个事件，精确边界及范围未知，不能宣称还原了隐藏事件总数。薄云/霾基准严重度取0.25，其余0.75。
- 数值：从探测数据扣除目标高度和月亮影响，使用偶数曝光的综合条件值校准每夜尺度；邻近目标先合并成曝光级样本。奇数曝光不参与拟合，用于另行检查。有效 sky_quality 是吸收综合差异的参数，不是恢复的真实天空质量。缺少有效样本的夜晚继续使用固定种子的参考天气。
- 停机：根据交接明示日期恢复C1三段长期停机及一次短维护、D1四次短维护；全角/中文时间由人工转录并保留完整来源，短时段按900秒槽起点近似，槽内边界仍有误差。
- 故障：已成功修复所证明的数量与真假报告时序来自正常运行记录；起点和效率仍为假设。D1正常运行仅有前三个修复的证据，未检出或后期故障仍可能未恢复。探测版不修复故障，不能直接拿其总分作基线。
- D1：恢复40%数据丢失上限与收到的比例；触发时间用正常运行的通知时刻作近似，窗口按本次行动数量重新计算。指向偏差尚未知，暂取0。

事件证据、维护来源与夜尺度在每卡 generator/。这是固定场景的本地响应/对比材料，不能保证线上同分或用拟合场景声称泛化到未知天气。

## 使用

```sh
python3.12 agents/claude-baseline-v1/tools/run_eval.py --eval-set formal-v5-new-four-reconstructed-v1 --tag new-four-v5
```

默认本地评测仍为旧A–D时间对齐套件；此处显式选择新套件。没有再次提交比赛或更改最终作品。重建命令：

```sh
python3 scripts/reconstruct-formal-timeline.py --new-capture artifacts/formal-card-refresh-2026-10-05/probe-new-four --out evaluation_assets/formal-v5-new-four-reconstructed-v1-copy
```
